# INDEX16.COM: V15 16bit indexed LD 実機テスト

## 実行前の注意

**16bit indexed LDを追加したRTLでFPGAを再ビルド・書込みしてから実行する。**
旧FPGAでは対象コードが従来のZ80命令として実行されるため、このCOMは使わない。
バンク操作命令のコード移設、IBR/RSTの仕様変更はまだ行っていない。

MSX-DOSから`INDEX16`を実行する。正常時:

```text
PASS=18 FAIL=00
```

18は16進数で24判定。フリーズせずDOSへ復帰することも確認する。
2026-10-24、ユーザーから実機で`PASS=18 FAIL=00`の報告あり（全24判定PASS）。
DOSへの復帰は明示報告なし。使用ビットストリームのハッシュと配置配線結果は未記録。
実機確認の範囲は本COMのM1テストであり、M2の実機確認を意味しない。

## 内容

M1で、IX/IY × BC/DE/HL × 読出し/書込みの12命令を、次の2条件で実行する。

| ケース | インデックスと変位 | 実効アドレス |
|---|---|---|
| 00〜0B | `01:FFFF + 00` | `01:FFFF`、2byte目は`02:0000` |
| 0C〜17 | `02:0000 + FF(-1)` | `01:FFFF`、2byte目は`02:0000` |

各12ケースの前半6件はBC/DE/HLへの読出し、後半6件は書込み。
各ペア内でIX、IYの順に実行する。
メモリ使用はbank00(コード・結果・通常スタック)、bank01、bank02のみ。

対象命令:

- DD/FD 07/17/27 d: BC/DE/HLへ2byte読出し
- DD/FD 0F/1F/2F d: BC/DE/HLを2byte書込み

読出しでは対象ペアを1234からBEEFへ変更し、他ペアの保持を確認する。
書込みでは事前にメモリへ1234を書き、BEEFへの変更を確認する。
加えてIX/IY、各データバンク、F=D7の保持を確認する。
今回のCOMは複数パターンの全メモリ試験ではない。
広い組合せのMODE/WAIT/変位試験は[432ケースのRTL検証](../../verification_data/v15_index16/README.md)を参照。

測定はDI/M1で行い、結果をbank00へ保存してM0へ戻し、
使用バンクをクリアしてから割込み許可・BDOS表示を行う。

FAIL時はケース番号、最初の不一致のoffset、got/wantを16進表示する。
offsetの意味:

| offset | 値 |
|---|---|
| 00〜05 | BC/DE/HLの低位・上位 |
| 06〜09 | IX/IYの低位・上位 |
| 0A〜0E | BC/DE/HL/IX/IYのバンク |
| 0F | F |
| 10〜11 | `01:FFFF`、`02:0000`の読戻し |

## ビルド

z88dk-z80asmとmakeがPATHにあるWindows環境で、このフォルダから`make`。
生成先は`bin\index16.com`。ソース内の自己書換えはM0で行う。
本体は[INDEX24](../Index24Test/README.md)と共用する。
通常のビルドはINDEX16、INDEX24定義付きの取り込み時だけ3byte転送の試験になる。

## COM実行回帰

リポジトリルートから:

```powershell
& .\fpga\G80A\test\run_index16_com.ps1
```

実際に生成したCOMをT80で実行する。通常実行に加え、
bank01:FFFFの読出しを00にする故障注入で全24ケースがFAILすることも確認する。
M0のBDOS、M1のDI維持、周期的なIM1割込み、DOS終了を検証する。
メモリモデルはbank00/01/02の3バンク。
物理SDRAM・実際のDOS/BIOSやWAIT調停を再現するものではない。
記録は[検証データ](../../verification_data/index16_com/README.md)へ保存する。

## M2実機用 I16M2.COM

同じ`make`で`bin\i16m2.com`も生成する。
今回のindexed LD対応FPGAで、MSX-DOSから`I16M2`を実行する。
期待値はM1版と同じ`PASS=18 FAIL=00`（24判定）。DOS復帰も確認する。
2026-10-24、ユーザーからI16M2.COMの実機結果`PASS=18 FAIL=00`（全24判定PASS）の報告あり。
DOS復帰は明示報告なし。非ゼロPCバンク等、以下の対象外条件まで確認したものではない。

命令・変位・対象アドレス・転送結果の比較はM1版と同じで、
測定区間だけDI/M2とする。コード・結果と専用32byteスタックはbank00のCOM内に置く。
M2へ入る前にMSP24を専用スタック末尾（bank00）へ設定する。
M2内のPUSH/POPは通常SPではなくMSP24を使い、測定終了後はM0へ戻して
バンクをクリアし、EIしてからBDOSを呼ぶ。M2の割込み仕様は変更しない。
MSP24は試験用の値のまま終了し、実行前のMSP24値へは復元しない。

従来の18byteの比較へ、MSP24の低・高・バンクと通常SPの低・高を追加する。
FAIL offset12/13/14はMSP24、15/16は通常SP（いずれも16進数）。
MSP24は各ケースの準備値から変わらず、通常SPはM0で記録した値から変わらないことを確認する。
M2の非ゼロPCバンク、命令フェッチ境界、MSP24のバンク境界、割込み受理は対象外。
使用メモリモデルは3バンクのまま。

COM実行回帰:

```powershell
& .\fpga\G80A\test\run_index16_com.ps1 -M2
```

通常・故障注入とも期待どおりの集計と終了を確認し、
全24ケースが実際にM2へ入ることもアサートする。
[M2版のログ・ハッシュ](../../verification_data/index16_m2_com/README.md)はM1版と分離する。
