# INDEX16.COM実行検証

入力は[実機テストのソース](../../hardware_test/Index16Test/index16_test.asm)を
ビルドしたCOM。命令列・期待値は同ソースを参照する。

- `fault-false.log`: 通常実行の全24判定と集計。
- `fault-true.log`: bank01:FFFFの読出しを00に置換した全24判定と集計。
- `summary.json`: 検証日時、GHDL版、入力COMとソースのSHA-256。

再実行手順は[実機テストREADME](../../hardware_test/Index16Test/README.md)を参照。
ログとサマリーは再実行で上書きする。中断・失敗時の一部ログを成功結果と解釈しない。
各ファイルの日時とハッシュを照合すること。
これはシミュレーション結果であり、実機検証済みを意味しない。
