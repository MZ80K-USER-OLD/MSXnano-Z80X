## MMU実装詳細

MMUはCPUの24bit論理アドレス空間とFPGA上の物理メモリ空間を分離する。CPU内部で生成された24bit論理アドレスを直接SDRAM等へ接続せず、必ずMMU変換段を通して物理アドレスおよびmemory
target選択信号を生成する。

``` text
CPU logical address (24bit)
        ↓
       MMU
        ↓
FPGA physical address
        ↓
 ┌──────┼───────┐
SDRAM  BSRAM  MSX slot / other target
```

### MMUレジスタ

現仕様の基本構成として256個の8bit bank registerを持つ。bank
00はMSX/Z80互換動作用として扱い、既存方針どおりI/O port `F0/F1` をMMU
registerの選択・アクセスに使用する。

MMU register fileについては、FPGA資源使用量とread
timingを確認し、distributed registerまたはblock
RAM等の実装方式を決定する。

### MODEとの関係

M0では既存MSX/Z80互換性を優先し、16bit CPU addressをbank
00側の論理空間として扱う。

M1ではPCは16bit互換実行を維持しながら、BC24/DE24/HL24/IX24/IY24等から生成されたdata
addressについて24bit MMU変換を使用する。

M2ではinstruction fetch、data access、MSP stack
accessを含め、PC24等から生成される24bit論理アドレスをMMUへ入力する。

### byte単位のMMU変換

複数byteのload/storeを一度だけ変換して連続物理addressとして扱わない。各byteの論理アドレスについてMMU変換を行う。

例:

``` text
LD24 HL,(IX+d)

EA24+0 → MMU → physical address → HL_L
EA24+1 → MMU → physical address → HL_H
EA24+2 → MMU → physical address → HL_B
```

これにより `xx:FFFF`
等の境界を跨ぐアクセスでも、次の論理bank/pageに対して正しいMMU
mappingを適用できる。

同じ原則を以下へ適用する。

-   16/24bit load/store
-   IX/IY indexed access
-   PUSH24/POP24
-   CALL.L/RET.L
-   CALL.Mx/RET.M
-   M2 interrupt frame
-   M2 instruction fetch

### MMU単体テスト

CPU統合前にMMU単体testbenchを用意し、最低限以下を確認する。

-   MMU register select/write/read
-   bank 00互換動作
-   任意logical bankのmapping
-   physical address生成
-   SDRAM/BSRAM/MSX slot等のtarget選択
-   `xx:FFFF → xx+1:0000` 境界跨ぎ
-   mappingの異なる隣接bankへの連続byte access
-   reset後のMMU状態
-   M0/M1/M2それぞれのaddress経路

MMU単体検証完了後に24bit ALU/EA生成回路と接続し、その後indexed
LD、stack、control
flow、interruptの順でMMU経路を使用する機能を統合する。

## 各Phaseの基本検証サイクル

``` text
RTL変更
  ↓
Z80回帰テスト
  ↓
追加した24bit命令テスト
  ↓
MSX起動テスト
```

M0のZ80/MSX互換性を継続的に確認する。24bit機能の追加によって既存Z80命令の挙動、タイミング、フラグ、メモリアクセスが変化していないことを各Phaseで確認する。

## 実装順序の基本方針

Phase
1～9で「24bit値を保持する・演算する・アドレスを生成する・メモリへ読み書きする」基本データパスを完成させる。

その後、Phase 10以降でMSP24、24bit制御フロー、mode
CALL、M2割り込みを実装する。この順序により、制御フローや割り込みの不具合を、24bit
ALU・MMU・アドレス生成の不具合から切り分けやすくする。

## 完成判定

-   M0で既存Z80/MSXソフトウェアとの互換動作を維持する。
-   M1で24bitデータアドレッシングが正常動作する。
-   M2でPC24/MSP24を含む24bitネイティブ実行が正常動作する。
-   IX/IYのDD/FD拡張命令が仕様どおり動作する。
-   MMUを介した24bit論理アドレスからFPGA物理メモリへの変換が正常動作する。
-   64KB境界を跨ぐ24bitメモリアクセス、stack、CALL/RETが正常動作する。
-   IVR24/NVR24を使用したM2 IRQ/NMIと復帰処理が正常動作する。
-   Tang Nano 20K上でtiming closureし、MSXシステムとして実機動作する。
