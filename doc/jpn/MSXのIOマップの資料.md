# 1chipMSX / OCM-PLD I/Oポートマップ仕様書

1chipMSXおよびOCM-PLDファームウェア環境における、Z80 CPUから見たI/Oポート（下位8bitアドレス空間 `00h`〜`FFh`）の割り当て状況および詳細仕様をまとめた資料です。

---

## 1. I/Oポートアドレス一覧

| :--- | :--- | :--- |
| **`10h` 〜 `2Eh`** | **完全フリーエリア** | **【自作・実験推奨】** 標準周辺機器を含め衝突のリスクがありません。 |
| `40h` 〜 `4Fh` | 拡張スイッチドI/O | 1chipMSX固有。システム制御、スロットマップ切り替え、DIPSW状態保持。 |
| `7Ch` 〜 `7Dh` | FM音源 (MSX-MUSIC) | 内蔵OPLL（YM2413互換コア）。 |
| `7Eh` 〜 `7Fh` | リアルタイムクロック (RTC) | RP-5C01互換コア（時刻・システム設定データ保持）。 |
| `8Eh` 〜 `8Fh` | VDP拡張ポート | V9958の追加拡張レジスタ（ファームウェアによる）。 |
| **`98h` 〜 `9Bh`** | **VDP (ビデオプロセッサ)** | V9958互換コア。VRAMアクセス、レジスタ、パレット制御。 |
| **`A0h` 〜 `A2h`** | **PSG (音源 / I/Oポート)** | AY-3-8910互換コア。音源、ジョイスティック、キーボード。 |
| **`A6h`** | **SDカード / 拡張BIOS** | **【1chipMSX特有】** SPI通信によるMMC/SDカードアクセス制御。 |
| **`A8h` 〜 `ABh`** | **PPI (システム制御用IC)** | 8255互換。基本スロット（A8h）、キーボード等の制御。 |
| `B4h` 〜 `B5h` | リアルタイムクロック (RTC) | `7Eh`〜`7Fh` のミラー（または特殊拡張、競合注意）。 |
| **`B8h` 〜 `BFh`** | **汎用空きエリア** | **【自作準推奨】** 歴史的にMSXの自作ハードでよく使われるエリア。 |
| `D0h` 〜 `D7h` | フロッピーディスク (FDC) | WD2793互換（内部エミュレーションによるDISK BASIC用）。 |

| **`FCh` 〜 `FFh`** | **メモリーマッパー** | 内蔵1MB（またはそれ以上）のRAMページ（4バンク）切り替え。 |

## 2. 主要ポートの詳細仕様

### 2.1 VDPポート (`98h` 〜 `9Bh`)
MSX2+/turboR準拠のV9958コアがマッピングされています。
* `98h` (R/W): VRAMデータ
* `99h` (W)  : VDPレジスタ書き込み / レジスタアドレス設定
* `99h` (R)  : VDPステータスレジスタ読み出し
* `9Ah` (W)  : パレットレジスタ設定
* `9Bh` (W)  : 間接レジスタ指定

### 2.2 PPIポート (`A8h` 〜 `ABh`)
システム全体の基本スロット切り替えや、キーボード入力を担当します。
* `A8h` (R/W): 基本スロットレジスタ
  * Bit 0-1: ページ0 (0000h-3FFFh) のスロット選択
  * Bit 2-3: ページ1 (4000h-7FFFh) のスロット選択
  * Bit 4-5: ページ2 (8000h-BFFFh) のスロット選択
  * Bit 6-7: ページ3 (C000h-FFFFh) のスロット選択
* `A9h` (R)  : キーボードマトリクスデータ入力
* `AAh` (W)  : 一般出力（キーボード行選択、LED制御、カセット制御）

### 2.3 メモリーマッパーポート (`FCh` 〜 `FFh`)
メインRAMのセグメント（1セグメント＝16KB）を切り替えます。
* `FCh` (R/W): ページ0 (0000h-3FFFh)
* `FDh` (R/W): ページ1 (4000h-7FFFh)
* `FEh` (R/W): ページ2 (8000h-BFFFh)
* `FFh` (R/W): ページ3 (C000h-FFFFh)

## 3. 開発時の注意点と衝突リスク

1. **`E0h` 〜 `E7h` 領域の危険性**
   * この領域は `E0h-E2h` (MSX-MIDI) と `E4h-E7h` (S1990/turboR倍速制御) で占有されています。
   * 背面のDIPスイッチ設定（動作モードや速度設定）は、FPGA内部でこれら `S1990` 互換レジスタや拡張スイッチドI/Oを介してシステムに反映されています。
   * この領域（特に空きに見える `E3h` など）を自作プログラムで叩くと、**本体の動作モード誤認、速度異常、ハングアップなどの予期せぬ衝突**を引き起こします。

2. **安全な設計のための推奨**
   * 1chipMSX上で自作の周辺機器（ハードウェア）やプログラム用のI/Oを設ける場合は、完全にクリーンな **`10h` 〜 `2Eh`** の範囲を強く推奨します。
