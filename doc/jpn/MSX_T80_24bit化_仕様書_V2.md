# MsxNano T80 24-bit Extension Instruction Set Specification
**【確定版命令仕様書】**

## 1. 凡例とビットパターン規則
* すべての命令は **`ED` プリフィックス** が前置される2バイト以上の命令です。
* **即値アドレス (`ext24`)**: `bl, bh, bn`（下位アドレス、上位アドレス、バンク番号）の順の3バイト即値。
* **相対オフセット (`offset16`)**: `dl, dh`（16ビット符号付き相対オフセット）の2バイト即値。
* **変位 (`d`)**: `d`（8ビット符号付きインデックス変位）の1バイト即値。
* **フラグ条件 (`cc`)**: Z80標準の全8条件（`NZ`, `Z`, `NC`, `C`, `PO`, `PE`, `P`, `M`）に対応。
* **条件コードの2バイト目規則**: Z80標準命令（`CALL`, `JP`, `RET`）のビットパターンを100%そのまま流用し、既存のフラグ判定回路を完全に再利用します。

## 1.1 opcode割り当ての基本方針（確定）

本仕様のED拡張命令は、可能な限りZ80の既存opcodeをそのまま利用します。

- Z80に対応命令が存在する場合：`ED + 元のZ80 opcode`。
- 例：`JR 18` → `ED 18 JR.L`、`JP C3` → `ED C3 JP.L`、`CALL CD` → `ED CD CALL.L`、`RET C9` → `ED C9 RET.L`。
- Z80に存在しない新命令はED opcode空き領域から割り当てます。
- `SET_M0/M1/M2` は例外的な新規制御命令として `ED 90/91/92` に固定します。

## 3. 24ビット演算・データロード・ブロック転送命令（Xシリーズ）
※ `ADD`/`SUB` などの24ビットレジスタペア加減算は、メインALUのクリティカルパス（遅延）を防ぐため、既存の16ビットALUを2クロック使い回す「マルチサイクル処理」としてFPGAに実装します。

| オプコード (HEX) | 命令表記 | 拡張バイト | 挙動概要 |
| :--- | :--- | :--- | :--- |
| **`ED 03`** | `INC XBC` | なし | `BC_B:BC` を24ビット演算で `+1` (桁上げ連動) |
| **`ED 13`** | `INC XDE` | なし | `DE_B:DE` を24ビット演算で `+1` (桁上げ連動) |
| **`ED 23`** | `INC XHL` | なし | `HL_B:HL` を24ビット演算で `+1` (桁上げ連動) |
| **`ED 33`** | `INC XSP` | なし | `MSP_B:MSP` を24ビット演算で `+1` (桁上げ連動) |
| **`ED 0B`** | `DEC XBC` | なし | `BC_B:BC` を24ビット演算で `-1` (桁下げ連動) |
| **`ED 1B`** | `DEC XDE` | なし | `DE_B:DE` を24ビット演算で `-1` (桁下げ連動) |
| **`ED 2B`** | `DEC XHL` | なし | `HL_B:HL` を24ビット演算で `-1` (桁下げ連動) |
| **`ED 3B`** | `DEC XSP` | なし | `MSP_B:MSP` を24ビット演算で `-1` (桁下げ連動) |
| **`ED 3D`** | `CP XHL, XDE` | なし | `(HL_B:HL) - (DE_B:DE)` を24ビット丸ごと減算比較、フラグのみ変化 |
| **`ED 09`** | `ADD XHL, XBC` | なし | `(HL_B:HL) + (BC_B:BC)` -> `XHL` (桁上げ連動・2サイクル処理) |
| **`ED 19`** | `ADD XHL, XDE` | なし | `(HL_B:HL) + (DE_B:DE)` -> `XHL` (桁上げ連動・2サイクル処理) |
| **`ED 29`** | `ADD XHL, XHL` | なし | `XHL` を2倍にする (24ビット左シフトと同等) |
| **`ED 39`** | `ADD XHL, XSP` | なし | `(HL_B:HL) + (MSP_B:MSP)` -> `XHL` (桁上げ連動・2サイクル処理) |
| **`ED 0A`** | `SUB XHL, XBC` | なし | `(HL_B:HL) - (BC_B:BC)` -> `XHL` (桁下げ連動・2サイクル処理) |
| **`ED 1A`** | `SUB XHL, XDE` | なし | `(HL_B:HL) - (DE_B:DE)` -> `XHL` (桁下げ連動・2サイクル処理) |
| **`ED 31`** | `LD XSP, ext24` | `dl, dh, db` | 24ビットスタック（MSP）へ3バイト即値をロード |
| **`ED 32`** | `LD XHL, ext24` | `dl, dh, db` | `HL_B:HL` へ3バイト即値を一括ロード |
| **`ED 2A`** | `LD XHL, (ext24)` | `bl, bh, bn` | 指定24ビット物理アドレスから直接3バイトロード |
| **`ED 22`** | `LD (ext24), XHL` | `bl, bh, bn` | `XHL`の3バイトを指定24ビット物理アドレスに直接セーブ |
| **`ED 4F`** | `LD XBC, (XHL)` | なし | `XHL` が指すアドレスから `XBC` へ間接3バイトロード |
| **`ED 5F`** | `LD XDE, (XHL)` | なし | `XHL` が指すアドレスから `XDE` へ間接3バイトロード |
| **`ED 47`** | `LD (XHL), XBC` | なし | `XHL` が指すアドレスへ `XBC` の3バイトを間接セーブ |
| **`ED 57`** | `LD (XHL), XDE` | なし | `XHL` が指すアドレスへ `XDE` の3バイトを間接セーブ |
| **`ED 6F`** | `LDIR24` | なし | **24ビットブロック一括転送** (16MB全域自動連続コピー)<br>`((XHL)->(XDE), INC XHL, INC XDE, DEC XBC を XBC==0 まで)` |

## 4. 3バイト PUSH / POP 命令（M2モード用）
※ 現在の動作モード（Mフラグ）の作法に自動連動します（M2なら3バイト退避、M0/M1なら2バイト退避として動作）。

| オプコード (HEX) | 命令表記 | 拡張バイト | 挙動概要 |
| :--- | :--- | :--- | :--- |
| **`ED C5`** | `PUSH XBC` | なし | スタック（M2時はMSP、M0/M1時はUSP）へレジスタとバンクを退避 |
| **`ED D5`** | `PUSH XDE` | なし | スタックへレジスタとバンクを退避 |
| **`ED E5`** | `PUSH XHL` | なし | スタックへレジスタとバンクを退避 |
| **`ED F5`** | `PUSH XAF` | なし | スタックへレジスタと現在の `PC_B`（実行バンク）を退避 |
| **`ED C1`** | `POP XBC` | なし | スタックからポップし、`BC_B:BC` を復元 |
| **`ED D1`** | `POP XDE` | なし | スタックからポップし、`DE_B:DE` を復元 |
| **`ED E1`** | `POP XHL` | なし | スタックからポップし、`HL_B:HL` を復元 |
| **`ED F1`** | `POP XAF` | なし | スタックからポップし、`PC_B`, `A`, `F` を復元 |

## 5. 無条件・条件付き 24ビット制御（分岐・コール・リターン）命令
※ Z80に対応する既存命令がある場合、そのZ80 opcodeを `ED` prefixの後ろにそのまま使用する「Z80 opcode mirror方式」を採用します。`JP/CALL/RET` の条件コードもZ80標準opcodeとの対応を維持します。拡張相対 `JR.L` は通常のZ80 `JR` opcodeを利用し、変位を8bitから16bitへ拡張します。

| オプコード (HEX) | 命令表記 | 拡張バイト | 挙動概要 |
| :--- | :--- | :--- | :--- |
| **`ED C3`** | `JP.L ext24` | `bl, bh, bn` | Z80 `C3 JP nn` の24ビット拡張。PC_B と PC を同時に書き換え |
| **`ED C2` / `CA`** | `JP.L NZ / Z, ext24` | `bl, bh, bn` | Z80条件JPの24ビット拡張 |
| **`ED D2` / `DA`** | `JP.L NC / C, ext24` | `bl, bh, bn` | Z80条件JPの24ビット拡張 |
| **`ED E2` / `EA`** | `JP.L PO / PE, ext24` | `bl, bh, bn` | Z80条件JPの24ビット拡張 |
| **`ED F2` / `FA`** | `JP.L P / M, ext24` | `bl, bh, bn` | Z80条件JPの24ビット拡張 |
| **`ED 18`** | `JR.L offset16` | `dl, dh` | Z80 `18 JR e` の拡張。16bit符号付き相対変位 |
| **`ED 20` / `28`** | `JR.L NZ / Z, offset16` | `dl, dh` | Z80 `20/28 JR NZ/Z,e` の拡張 |
| **`ED 30` / `38`** | `JR.L NC / C, offset16` | `dl, dh` | Z80 `30/38 JR NC/C,e` の拡張 |
| **`ED C7` / `D7`** | `JR.L PO / PE, offset16` | `dl, dh` | Z80に対応するJRなし。新規拡張 |
| **`ED E7` / `F7`** | `JR.L P / M, offset16` | `dl, dh` | Z80に対応するJRなし。新規拡張 |
| **`ED CD`** | `CALL.L ext24` | `bl, bh, bn` | Z80 `CD CALL nn` の24ビット拡張。MSPに3バイト退避 |
| **`ED C4` / `CC`** | `CALL.L NZ / Z, ext24` | `bl, bh, bn` | Z80条件CALLの24ビット拡張 |
| **`ED D4` / `DC`** | `CALL.L NC / C, ext24` | `bl, bh, bn` | Z80条件CALLの24ビット拡張 |
| **`ED E4` / `EC`** | `CALL.L PO / PE, ext24` | `bl, bh, bn` | Z80条件CALLの24ビット拡張 |
| **`ED F4` / `FC`** | `CALL.L P / M, ext24` | `bl, bh, bn` | Z80条件CALLの24ビット拡張 |
| **`ED C9`** | `RET.L` | なし | Z80 `C9 RET` の24ビット拡張。スタックから3バイト復帰 |
| **`ED C0` / `C8`** | `RET.L NZ / Z` | なし | Z80条件RETの24ビット拡張 |
| **`ED D0` / `D8`** | `RET.L NC / C` | なし | Z80条件RETの24ビット拡張 |
| **`ED E0` / `E8`** | `RET.L PO / PE` | なし | Z80条件RETの24ビット拡張 |
| **`ED F0` / `F8`** | `RET.L P / M` | なし | Z80条件RETの24ビット拡張 |
| **`ED 4E`** | `RETI.L` | なし | M2モード用24ビット割り込み復帰専用命令（MSPから3バイト復帰） |

*※ `JR.L` のオフセット加算によって16ビット境界をはみ出した場合は、`PC_B`（バンク）を書き換えずに16bit境界でラップアラウンド（巡回）します。*

### Z80 opcode mirror方式

24bit拡張命令のopcode割り当ては、以下を正式な設計原則とします。

1. Z80に対応する既存命令がある場合、そのZ80 opcodeを `ED` prefixの後ろにそのまま使用する。
2. 条件付き命令はZ80の条件コードとopcode対応を維持する。
3. オペランド幅だけを拡張する場合、元のZ80命令の意味を維持し、アドレス／データ幅を拡張する。
4. Z80に存在しない新命令は、ED opcode空き領域から新規割り当てする。
5. `JR.L` は `ED 18/20/28/30/38` を正式採用し、旧 `ED 60～67` 系は使用しない。
6. `SET_M0/M1/M2` は確定済みの `ED 90/91/92` を使用し、他の命令へ再割り当てしない。

### 旧割り当てからの変更

- `ED 70/71/72` → `SET_M0/M1/M2` には使用しない。正式仕様は `ED 90/91/92`。
- `ED 60～67` → `JR.L` には使用しない。
- `ED 5C` → `JP.L ext24` には使用しない。正式仕様は `ED C3`。
- `ED 22` → `CALL.L ext24` には使用しない。正式仕様は `ED CD`。`ED 22` は `LD (ext24),XHL` のまま。
- `ED 6B` → `RET.L` には使用しない。正式仕様は `ED C9`。


## 6. 実効アドレス演算・スタック退避命令（PEA / LEA シリーズ）
※ インデックス加算およびバンク桁上げ処理は、メインALUを2サイクル使い回すことでFPGAの遅延（クリティカルパス）を防止します。各モードの制限（M2なら3バイト、M0/M1なら2バイト）に完璧に順応して動作します。

* **`DD ED` プリフィックス**: `IX` レジスタを指定
* **`FD ED` プリフィックス**: `IY` レジスタを指定

| オプコード (HEX) | 命令表記 | 拡張バイト | 挙動概要 |
| :--- | :--- | :--- | :--- |
| **`DD ED 68 d`** | `LEA.L XHL, (XIX+d)` | `d` (1B変位) | `(IX_B:IX) + d` の24bitアドレスを `XHL` にロード |
| **`FD ED 68 d`** | `LEA.L XHL, (XIY+d)` | `d` (1B変位) | `(IY_B:IY) + d` の24bitアドレスを `XHL` にロード |
| **`DD ED 69 d`** | `LEA.L XDE, (XIX+d)` | `d` (1B変位) | `(IX_B:IX) + d` の24bitアドレスを `XDE` にロード |
| **`DD ED 6A d`** | `PEA.L (XIX+d)` | `d` (1B変位) | `(IX_B:IX) + d` の24bitアドレスそのものをスタックにプッシュ |
| **`FD ED 6A d`** | `PEA.L (XIY+d)` | `d` (1B変位) | `(IY_B:IY) + d` の24bitアドレスそのものをスタックにプッシュ |

## 7. Z80標準ブロック転送・I/O命令（周辺デバイス制御用リファレンス）
※ M2モード下でもそのまま完全に有効であり、MSXのVDPやPSGなどの周辺ICの制御、およびVRAMへの一括高速データ転送にそのまま利用可能です。

| オプコード (HEX) | 命令表記 | 拡張バイト | 挙動概要 |
| :--- | :--- | :--- | :--- |
| **`ED A0`** / **`A8`** | `LDI` / `LDD` | なし | `(HL)`➔`(DE)`へ1バイト転送、`HL`/`DE`を `+1`/`-1`、`BC`を `-1` |
| **`ED B0`** / **`B8`** | `LDIR` / `LDDR` | なし | `LDI`/`LDD` 命令を `BC` が 0 になるまで自動連続実行 |
| **`ED 78`** / **`48`** | `IN A, (C)` / `OUT (C), A` | なし | Cレジスタで指定したI/OポートからAレジスタへ入出力 |
| **`ED A2`** / **`A3`** | `INI` / `OUTI` | なし | I/Oポート(C)➔`(HL)`へ転送、またはその逆。`HL`は`+1`、`B`は`-1` |
| **`ED B2`** / **`B3`** | `INIR` / `OTIR` | なし | `INI`/`OUTI` 命令を Bレジスタ が 0 になるまで自動連続実行（**VRAM高速転送**） |
