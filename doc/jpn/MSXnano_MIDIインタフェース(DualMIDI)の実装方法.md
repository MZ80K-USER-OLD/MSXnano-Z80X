# MSXnanoへのDual MIDI実装ガイド

本ドキュメントは、**MSXnano（Tang Nano 20K）**に**Dual MIDIインターフェース**を実装し、M5StackのMIDIシンセサイザユニット（SAM2695）を接続して「MSPLAY.COM」からMIDI演奏を行うための手順をまとめたものです。

---

## 1. ハードウェアの接続・配線

Tang Nano 20KのGPIOピン（例として `IO17` を使用）と、M5Stack MIDIユニット（SAM2695）を以下のように接続します。

| Tang Nano 20K 側 | M5Stack MIDIユニット側 | 役割・備考 |
| :--- | :--- | :--- |
| **5V** (またはVCC5V) | **5V** | ユニット電源用 |
| **GND** | **GND** | グランド |
| **IO17** (任意のGPIO) | **IN** (MIDI信号入力) | FPGAからのMIDIシリアル出力 (TxD) |
| (未接続) | **NC** | 使用しません |

### ⚠️ 電気的特性に関する注意点
* **電圧レベル変換 (レベルシフト):** Tang Nano 20KのGPIOは **3.3Vロジック**、M5Stackユニットは **5V駆動** です。ダイレクト接続でも動作することが多いですが、もし認識しない場合や波形が乱れる場合は、「Xian DIY 5V <-> 3.3V双方向ロジックレベル変換モジュール」等のレベルシフターを信号線（IO17 ↔ IN）に挟んでください。
* **信号の論理レベル:** MIDIシリアル信号（UART）は、**アイドル（無送信）状態のとき「High (1)」**となります。FPGAの出力初期値が `1` になるように実装してください。

---

## 2. FPGA（Verilog）の実装仕様

MSXnanoのI/Oデコード部およびトップモジュールに、**「Dual MIDIポート（04h/05h）」**の処理と**「31,250 bpsのUART送信モジュール」**を追加します。

### I/Oポート仕様
* **ポート `04h` (Write専用 / データポート):** 
  CPUからこのポートにデータが書き込まれたら、その1バイトをUART送信レジスタにラッチし、シリアル送信（31,250 bps）を開始します。
* **ポート `05h` (Read専用 / ステータスポート):** 
  CPUがこのポートの状態を読み取った際、**Bit 0（送信バッファ空きフラグ）を常に `1`**（送信可能状態）にしてデータバスへ返します。これにより、ソフトウェアはウェイトなしで最速でMIDIデータを送信できます。

### Verilogコードスニペット例

```verilog
// -------------------------------------------------------------
// Dual MIDI ポートデコードとUARTトリガーの実装例
// -------------------------------------------------------------

// ※ 命名ルール等に合わせ、必要に応じて変更してください
reg [7:0] uart_tx_data;
reg       uart_tx_start;

always @(posedge clk or negedge rst_n) begin
    if (!rst_n) begin
        uart_tx_data  <= 8'h00;
        uart_tx_start <= 1'b0;
    end else begin
        // I/Oライトアクセスかつ、ポートアドレスが 04h の場合
        if (io_write && (io_address == 8'h04)) begin
            uart_tx_data  <= io_write_data;
            uart_tx_start <= 1'b1; // UART送信モジュールへの送信要求
        end else begin
            uart_tx_start <= 1'b0;
        end
    end
end

// ステータスポート(05h)が読まれたら、常に「送信可能フラグ(Bit 0 = 1)」を返す
// (周辺のデータバス制御に合わせて MUX や 3ステートバッファに組み込んでください)
assign io_read_data = (io_read && (io_address == 8'h05)) ? 8'h01 : 8'hZZ;
```

## 3. MSX-DOS2上での演奏実行手順

FPGAの回路書き込みとハードウェア配線が完了したら、MSXnanoを起動してMSX-DOS2プロンプトから **`MSPLAY.COM`** を使用して演奏を行います。

### 実行コマンド
```bash
MSPLAY [ファイル名.MID] -M1
```

* **`-M1` オプションの重要性:** 
  このオプションを付けることで、MSPLAYはMSXのメインROM（BIOS）による「MSX-MIDI（ポートE8h/E9h）」の有無チェックをバイパスし、**Dual MIDIポート（04h/05h）へダイレクトにMIDIデータを流し込む**ようになります。これにより、BIOSの改造を行わずに外部音源を鳴らすことが可能になります。

---

## 4. トラブルシューティング

音が出ない、または演奏が乱れる場合は以下の項目を確認してください。

1. **通信速度（ボーレート）の一致:**
   SAM2695チップは標準のMIDI規格である **31,250 bps** で通信します。FPGAの分周比がメインクロックから正確に 31,250 bps を生成できているか（あるいは許容誤差内に収まっているか）を再確認してください。
2. **UART出力ピンの初期値:**
   前述の通り、MIDI通信はアイドル時に High (1) である必要があります。FPGAのリセット直後や未送信時に出力ピンが `0`（Low）に落ちていないか確認してください。
3. **レジスタ命名規則の推奨:**
   MSXnanoのプロジェクト内で新しく追加する独自のバンクや周辺レジスタの名前を定義する際は、可読性維持のため、既存の規則（例: `レジスタ名_Ｂ` などのフォーマット）に準拠して記述することをおすすめします。
